Wat je meet, en wat je niet meet

De pijplijn maakt twee soorten fouten, en maar één daarvan is zichtbaar. Een vals positief — VERDIEPEN dat op PASS uitkomt — kost uren, maar je ziet hem, want de analyse is gedaan. Een vals negatief — OVERSLAAN dat een KOOP was — kost een gemiste kans en blijft per constructie onzichtbaar, want die analyse komt er nooit.

  • VERDIEPEN met analyse: {{ vlek.verdiepen_getoetst[0] }} van {{ vlek.verdiepen_getoetst[1] }} — vals positieven zijn zichtbaar. {% if vlek.vals_pos %} Uitgekomen op PASS: {{ vlek.vals_pos | join(', ') }}. {% endif %}
  • OVERSLAAN zonder analyse: {{ vlek.overslaan_ongetoetst | length }} van {{ vlek.overslaan_totaal }} — vals negatieven zijn onzichtbaar. {% if vlek.overslaan_ongetoetst %} Het gaat om {% for t in vlek.overslaan_ongetoetst %}{{ t }}{% if not loop.last %}, {% endif %}{% endfor %}. {% endif %}
